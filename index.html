Fix the names, then send it back

Set the names and spots the way you actually want them, then export. That file is the playbook — drop it in the repo or send it over and the app ships your version. No code change, and you never have to describe an alignment to anyone.

Turn on Save to repo — about four minutes, once

  1. Make a GitHub token. Open the page ↗
    Resource owner Team-Formify · Repository access Only select repositories → Play-Designer · Permissions → Contents: Read and write. Generate, then copy it — it starts github_pat_ and GitHub only shows it once.
  2. Put it on Vercel. Open Vercel ↗
    Play-Designer → Settings → Environment Variables. Add GITHUB_TOKEN = the token you copied, and SAVE_SECRET = any passphrase you will remember.
  3. Check the branch. Settings → Git → Production Branch. If it is not main, add one more variable GITHUB_BRANCH set to whatever it says.
  4. Redeploy. Deployments → the top one → ⋯ → Redeploy. Variables only apply to new deployments.

Back up your work

Your plays live in this browser on this device only. Download a copy now and then — that file is the one thing that survives a cleared browser, a wiped phone, or a new one.

What the labels mean

  • Punt — LG/RG gunners, LT/RT tackles, LGD/RGD guards, S snapper, LW/RW wings, PP personal protector, P punter.
  • Punt return — LG/RG our two gunners jamming theirs, LH/MH/RH hold up, LM/RM second level, LW/MW/RW the wall, PR returner.
  • Kickoff — L5 to R5 by lane outward from the kicker, LG/RG the two gunner spots, K kicker.
  • Kick return — H1 to H5 the hands team, LM/RM and LB/RB the blockers, LR/RR the deep two.
  • An orange X beside a player means he is an X-man — on special teams he has to be on the front two lines or the line of scrimmage, and he cannot fake a punt.

How to use it

  • Move — drag any player. Tap one to select and rename it.
  • Route — tap a player, then tap the field to add points to his path. Tap the player again to finish.
  • Add — tap the field to drop a new player. Tap twice quickly for an opponent X.
  • Delete — tap a player to remove him.
  • Everything saves on this device automatically. Print makes a clean black-and-white sheet.
